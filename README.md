## 阅读说明

- **社区评分**：社区用户反馈形成的综合排序指标，保留一位小数。
- **可用性**：根据刷新时的源详情响应判断，订阅前仍建议在客户端内确认。
- **规模**：显示相册数、场景数与估算体积；若体积未上报，则显示为「—」。
- **概括**：结合源名称、公开简介与统计规模生成的正式化摘要，用于快速浏览。
